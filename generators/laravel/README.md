# Laravel Generator

`composer create-project laravel/laravel` officiel, kit Breeze optionnel (`blade`, `livewire`, `react`, `vue`, `api`, avec
`--dark`/`--pest`), base SQLite migrée et peuplée, formatage Pint, puis couche AlphaRust (pages, modèle, migration, seeder,
tests) branchée sans conflit avec Breeze. Vérifié par `php artisan test`. Couche : `templates/layers/laravel/`.
Code : `src/scaffold/laravel.rs`.
