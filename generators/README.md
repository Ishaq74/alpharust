# Generators

Générateurs intégrés à AlphaRust :

- **bootstrap** : initialise un projet minimal conforme
- **readme** : génère un README structuré
- **docs** : génère de la documentation technique
- **tests** : génère des squelettes de tests unitaires
- **checks** : génère des passes de vérification

Chaque générateur produit du code ou des fichiers alignés sur les règles AlphaRust.
