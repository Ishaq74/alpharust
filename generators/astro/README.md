# Astro Generator

`create-astro` officiel (`minimal`, `basics` ou `blog`) puis `astro add` pour les intégrations (Tailwind, MDX, sitemap,
React, Vue, Svelte), niveau TypeScript via les presets `astro/tsconfigs/*`, `astro check`, et — pour le template
`alpharust` — une structure complète (layout SEO accessible, thème clair/sombre, collection `blog` typée, 404…).
Gestionnaires : npm, pnpm, yarn, bun. Couche : `templates/layers/astro/`. Code : `src/scaffold/astro.rs`.
